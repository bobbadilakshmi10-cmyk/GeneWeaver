GeneWeaver is a web-based DNA sequence analysis project designed to process FASTA files and identify possible CRISPR target matches. The system accepts DNA sequence data, cleans and validates the sequences, converts them into a suitable format, and divides large sequences into overlapping chunks for analysis.
The project is developed using Python, Flask, BioPython, NumPy, HTML, CSS, and Bootstrap. The application provides a simple web interface where users can upload FASTA files and perform DNA sequence analysis. The project is designed with a modular architecture and can be extended with GPU acceleration for faster processing of large genomic datasets.
