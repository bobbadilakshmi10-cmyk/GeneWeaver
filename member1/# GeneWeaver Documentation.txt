# GeneWeaver Project Documentation
## Member 1: Data Pipeline and Results Display

### 1. Project Overview
GeneWeaver is a DNA sequence analysis project designed to process FASTA files, divide DNA sequences into smaller chunks, and prepare the data for further analysis, including CRISPR off-target mutation detection.

### 2. Member 1 Responsibilities
- Read and validate DNA sequences from FASTA files.
- Clean DNA sequences by converting lowercase letters to uppercase.
- Handle invalid DNA characters.
- Encode DNA bases into numerical values.
- Divide DNA sequences into smaller, overlapping chunks.
- Display processed DNA data and results in a readable format.
- Write and execute test cases to verify the data pipeline.

### 3. Technologies Used
- **Python:** Core programming language.
- **Biopython:** Reading and processing FASTA files.
- **NumPy:** Numerical representation of DNA sequences.
- **Rich:** Displaying progress bars and formatted result tables.
- **Pytest:** Testing and validating the pipeline.
- **Git and GitHub:** Version control and project collaboration.

### 4. Implementation Details

#### 4.1 FASTA File Processing
The pipeline reads DNA sequences from `data/sample.fasta` using the `prepare_data()` function.

#### 4.2 DNA Sequence Cleaning
DNA sequences are converted to uppercase, and whitespace is removed. Unsupported characters are checked and handled using validation.

#### 4.3 DNA Encoding
DNA bases are converted into numerical values:

| DNA Base | Encoded Value |
|---|---:|
| A | 0 |
| C | 1 |
| G | 2 |
| T | 3 |
| N | -1 |

#### 4.4 DNA Chunking
The DNA sequence is divided into smaller chunks of up to five bases. Overlapping chunks can be generated by moving one base at a time.

Example:

Original DNA sequence: `ATGCGA`

Chunk size: `5`

Overlapping chunks:
- `ATGCG`
- `TGCGA`

#### 4.5 Results Display
Processed DNA information can be displayed with the DNA ID, original sequence, DNA chunks, and encoded values. The Rich library can be used to display results in formatted tables.

### 5. Testing and Validation
The `test_pipeline.py` file is used to test the pipeline.

The tests verify that:
- DNA records are generated.
- Every record contains an ID.
- Every record contains a sequence.
- Each chunk contains no more than five DNA bases.

Example test output:

```text
All pipeline tests passed!
Total DNA chunks: 42
```

*The total of 42 chunks is an example based on the current sample data and should be confirmed by running the tests.*
